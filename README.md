# The Last Signal

A browser-based story game set in a dark, rain-soaked futuristic city. You play as Mira Holt, a courier racing through the night to uncover the truth behind a citywide blackout and decide the fate of the skyline.

## Features
- Branching storyline with multiple choices
- Character stats: health, energy, morale, and credits
- Inventory and mission log
- Multiple possible endings
- Responsive single-page interface

## Project files
- `index.html` — main game screen
- `style.css` — styling and layout
- `game.js` — story logic, stats, and endings

## How to run locally
You can run the game in two simple ways:

1. Open `index.html` directly in a browser
2. Or serve the folder locally:

```bash
cd my-first-ai-project
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages
If you want the game to work on GitHub Pages:

1. Go to your repository on GitHub
2. Open Settings
3. Click Pages
4. Set Source to `Deploy from a branch`
5. Select `main` and `/root`
6. Save

Then the game will be available at:

```text
https://<your-username>.github.io/my-first-ai-project/
```

## Story summary
The city is falling into darkness, and the only thing left alive is the signal. Your decisions determine whether the city is saved, controlled, or destroyed.
